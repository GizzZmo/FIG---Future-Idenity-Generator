## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/GizzZmo/FIG---Future-Idenity-Generator.git
   cd FIG---Future-Idenity-Generator
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set Gemini API Key**
   - Create `.env.local` and add:
     ```
     GEMINI_API_KEY=your-api-key
     ```

4. **Run locally**
   ```bash
   npm run dev
   ```
