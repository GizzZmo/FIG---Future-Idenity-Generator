## 🚀 Run & Deploy

This repository contains everything you need to run your app locally.

**View your app in [AI Studio](https://ai.studio/apps/drive/1Sw8aRQE4EVObwVsWvfL9pmATnpfw7O9i)**

### Prerequisites

- **Node.js** (latest recommended)

### Get Started

```bash
# 1. Install dependencies:
npm install

# 2. Set your Gemini API key:
# Edit .env.local and add GEMINI_API_KEY=<your-key>

# 3. Run the app:
npm run dev
```
